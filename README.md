## 🔍 How to Use the App

You use the app to check work done by AI tools. Follow these steps to verify your content.

1.  Open the AskProof application from your desktop shortcut.
2.  Paste the AI output into the text box on the screen.
3.  Click the "Verify" button.
4.  The application scans the text. It looks for logic gaps and unsupported claims.
5.  The app shows a report. Read this report to see if the AI provided evidence for its claims.
6.  If the app finds errors, you can use the built-in prompts to ask the AI for better proof.

## 💡 Best Practices

You get the best results when you use the tool in specific ways. 

### Verify Short Segments
If you have a long document, verify it in chunks. This helps the tool focus on specific facts.

### Use Clear Prompts
When the tool suggests a prompt, use it as written. You can change it if you have more context, but the basic form works best.

### Watch the Status Bar
The status bar shows you if the app is currently checking your text. Wait for the green checkmark before you rely on the results.

## 🛠️ Troubleshooting

Most issues arise from slow internet or interrupted connections.

*   Connection Error: Check your Wi-Fi settings. If the network drops, the app cannot send data to the verification engine. Restart the app after you reconnect to the internet.
*   App Won't Start: Restart your computer. Sometimes Windows locks the file during a fresh install. A reboot solves this issue.
*   Display Issues: Ensure your Windows scaling is set to 100%. If you use a large zoom setting, the interface might look strange. Change this in your Windows Display Settings.

## 📋 Frequently Asked Questions

### Does this app change my files?
No. The app only reads the text you paste into it. It does not modify your original documents.

### Does this use personal data?
The tool uses basic input to verify logic. It does not store your content on permanent servers. Your data stays on your machine.

### Can I run this offline?
The app needs the internet because it connects to an engine that checks logic. It will not work without an active web connection.

### How do I update the tool?
The app checks for updates every time you open it. If it finds a new version, it asks if you want to install it. Click "Yes" to keep your tool current.
